Diagnóstico de Basic Auth/CORS do vMix

Esta página usa a mesma origem HTTPS do PIBvMix no GitHub Pages e acessa o vMix diretamente. O usuário é fixo em admin. Nenhuma chamada altera o programa: todas apenas leem /api/.

Acesso à rede local: Chrome/Edge pode pedir permissão para esta página acessar dispositivos da LAN. Essa autorização é separada da senha do vMix. Para o teste prosseguir, permita o acesso local. Se negar, registre o aviso do navegador; nenhuma requisição à API terá sido feita.

Origem da página:

Destino: http://192.168.25.2:8088/api/

Digite a senha apenas ao executar. A página não a grava, inclui em URL ou log. Ela envia a senha correta e uma variação incorreta diretamente à API, somente em memória. Não compartilhe os valores de Authorization vistos no DevTools.

ChamadaResposta do fetchAccess-Control-Allow-OriginWWW-Authenticate

O JavaScript não consegue ler a resposta de um preflight que o navegador bloqueou. Para registrar o OPTIONS e os headers completos, abra DevTools → Network antes de executar, filtre por 192.168.25.2 e inspecione OPTIONS/GET. Não exporte HAR nem copie Authorization.
